# HLDRIVE v1.0.0

Release estável com interface, recursos e backend incorporados no ELF. O usuário informou que esta versão está testada e funcionando em seu PS5; firmware e cenário não foram especificados. O build desta publicação foi gerado localmente.

## Novidades

- QR codes para inscrição no canal do criador e apoio financeiro, exibidos discretamente na interface.
- Chamada para apoiar o desenvolvimento do projeto.
- Textos de uso e documentação atualizados para o HLDRIVE.
- Versões e metadados do atalho de Mídia atualizados.
- Porta HTTP 8081, downloads do Drive feitos diretamente pelo console e miniatura própria na aba Mídia.

Consulte [README](../../README.md), [compatibilidade](../COMPATIBILITY.md) e [validação](../TESTING.md).
